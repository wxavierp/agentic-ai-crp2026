# BITS Pilani Dubai — Agentic AI Engineering (CRP 2026)

Course code for the **Agentic AI Engineering** track, run by Tecoholic with
BITS Pilani Dubai Campus. Each week has its own folder with two parallel tracks:

- **`skeleton/`** — starter code with `TODO`s. **This is where you work.**
- **`trainer/`** — full reference solutions. Peek only if you're stuck.

## Getting started

1. Read **[SETUP.md](./SETUP.md)** — install Python, dependencies and one API key.
2. Open the current week's folder (start with `Week 1/`).
3. Read that week's `README.md`, then work through the numbered files in `skeleton/`.
4. Run the setup check first: `python "Week 1/skeleton/00_setup_check.py"`.

> Tip: **Groq** and **Google Gemini** both have generous free API tiers — ideal for this course.
